# SOP-projekt: RSA-kryptering

Dette projekt udgør mit SOP-arbejde om RSA-kryptering.

## Anvendte biblioteker
Projektet benytter følgende Python-biblioteker:

- **sympy** - bruges til talteori, primtal og matematiske beregninger  
- **matplotlib** - bruges til at generere grafer og visualiseringer

## Projektfiler

- **run.log**  
  Indeholder logdata over køretid for programmets forskellige dele samt eventuelle fejl.

- **results.json**  
  Indeholder resultaterne fra `testing.py`.

- **rsa.py**  
  Implementerer RSA-krypteringsalgoritmen.

- **plot.py**  
  Indeholder koden til generering af grafer vha. Matplotlib.

- **testing.py**  
  Importerer funktioner fra de øvrige filer og udfører testkørsler *(kør denne fil)*.
